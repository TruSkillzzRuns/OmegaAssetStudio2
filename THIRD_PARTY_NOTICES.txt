----------------------------------------------------------------
vgmstream - referenced, never distributed
----------------------------------------------------------------

   Upstream: https://vgmstream.org/
             https://github.com/vgmstream/vgmstream

The Voice Swapper can play the game's own sounds, which needs the decoder
vgmstream. It is NOT included here, and this project distributes no part of
it.

That is a deliberate choice rather than an oversight. A vgmstream release
carries a stack of codec libraries under mixed terms - the tool itself is
ISC-style, its FFmpeg and mpg123 components are LGPL-2.1-or-later, its Xiph
components are BSD-3-Clause, and its G.719 support derives from ITU-T
reference code whose terms are not a recognised open-source licence.
Redistributing all of that means carrying every one of those obligations for
a feature that is a convenience. Pointing at the upstream download costs the
user one click and costs this project nothing.

So the application looks for vgmstream-cli.exe rather than supplying it, in
this order: the folder the user chose, the folder the application runs from,
and then PATH. When it is not found the Voice Swapper says so and offers a
button to the upstream download page and a folder picker to point at a copy
already on the machine. Everything else in the tool works without it; only
listening is unavailable.

When the user does install it, they obtain it directly from upstream under
upstream's terms. This project is not in that chain, and no obligation of
vgmstream's licences attaches to this distribution. The application starts it
as a separate process and never links it.

================================================================
No GPL components
================================================================

This project distributes NO GPL-licensed component. The FFmpeg libraries above
are an LGPL build, which is a weaker obligation and is met as described.

Version 1 shipped a GPL-2.0-or-later native LZO library (lzo2_64.dll) and
carried the corresponding source-availability obligation. It is not present
here: cooked packages are LZO-compressed, and both the decompressor and the
compressor are implemented in managed code within this project.

One caveat, for the avoidance of doubt. A single test —
LzoAgainstReferenceTests — can check this project's compressor against the
reference LZO library by calling lzo2_64.dll, because agreeing with itself
proves nothing about what the game will accept. That file is NOT in this
repository, is listed in .gitignore, and is never distributed; the test skips
itself when it is absent. Anyone wanting to run it supplies their own copy and
must not commit it.

Action for distributors
================================================================

- Preserve this file in all binary distributions.
- Preserve LICENSE (MIT, this application).
- Do not bundle vgmstream or any of its codec libraries. The application
  locates a user-installed copy; adding one back to the distribution would
  pull in LGPL and ITU-T obligations this project does not otherwise carry.
- Never commit lzo2_64.dll. It is GPL, it is only used by one test, and
  .gitignore already excludes it.
- Ship no game content, ever. .gitignore excludes packages, caches, archives,
  and any model or texture exported from the game.
